## ✨ What This Application Does

ivi-analysis is built for equity research using SEC filings. In plain language, it helps you answer questions like:

- What numbers did this company report in its official filings?
- What did those numbers look like at a specific point in time, without later revisions changing the story?
- What is a repeatable valuation based on the filing data?
- Can an AI assistant help write an analyst memo using the same filing information?

The application focuses on public company research. It reads SEC filings, organizes the important financial information, and gives you a structured way to review it. The valuation side is deterministic, which means the same inputs should produce the same output each time. That makes it easier to compare companies, check your work, and understand how a valuation was built.

## 🧠 Why ivi-analysis Is Useful

Company research often involves jumping between filings, spreadsheets, and notes. ivi-analysis brings those pieces into a more organized workflow. You can look at official filing data, review fundamentals, and use valuation tools without building everything from scratch.

The point-in-time fundamentals are especially helpful because they show financial information as it was known at a chosen date. That matters when you want to study what an investor could have seen at the time, rather than looking only at the latest revised numbers.

The deterministic valuation feature is useful when you want repeatable calculations. You can change inputs, rerun the valuation, and compare results. The optional AI analyst memos can help turn filing details and valuation output into a written summary. You can use the application without the AI memo feature if you prefer to work manually.

## 🔍 How It Works in Plain English

ivi-analysis gathers company information from SEC filings. It organizes that information into fundamentals, which are the financial numbers and details used in research. The point-in-time part keeps track of when information was available, so you can study a company using the facts that were known at that time.

The valuation part uses clear, repeatable rules. You provide inputs, and the application calculates a result. Because the process is deterministic, you can rerun it and get the same answer when the inputs are the same. This is helpful for checking your work and comparing different companies.

The SEC MCP server acts like a bridge between filing data and AI tools that support MCP. The AI analyst memo feature is optional. It can help write a summary, but you remain in control of the research process.
